## 🧭 المبدأ اللي بيرتّب كل إشي تحت

الموقع **بيعي بالدفع عند الاستلام**. يعني في مسار واحد بيجيب المصاري:

```
تشوف منتج ← تضيفه للسلة ← تكمّل الطلب ← الطلب يوصلك ← يوصلها تأكيد
```

🔴 **أي حلقة مكسورة بهالسلسلة = صفر مبيعات، مهما كان الموقع حلو.**

فالترتيب: **المسار أول، الشكل ثاني، المحتوى ثالث.**
سكشن جميل على موقع ما بيقدر ياخد طلب هو ديكور.

الباقي (الروتينات · الكويز · المكوّنات · عن) **بعد الإطلاق**، لأن روابطها هلأ `#`
وما بتكسر إشي.

# 🚫 قائمة «لبعدين» · لو انشعبنا فيها اليوم ما بنخلص

هدول مش أولوية، وأنا رح أوقفك عنهم لو رحنا لهناك:

| الشي | ليش لبعدين |
|---|---|
| Microsoft Clarity | قرار ريّان صراحة · بعد ما يخلص الموقع |
| Image Optimization | ما في صور حقيقية بعد، فما في شغل تعمله |
| تنظيف الإضافات الزايدة | ما بيمنع بيعة وحدة · بعد الإطلاق |
| صفحات الروتينات الأربعة | روابطها `#` وما بتكسر إشي |
| صفحة الكويز | نفس الإشي |
| صفحة المكوّنات وصفحة «عن» | نفس الإشي |
| تنظيف مجلد `hero-sequence` | ترتيب داخلي · ما بيشوفه زبون |
| تعديل تصميم إضافي على الهيرو | خلص وشغّال · ما نفتحه من جديد |
| SEO و Rank Math | بعد ما يكون في محتوى حقيقي |
