# 🔎 فحص ما قبل الفهرسة · ٤ أيلول ٢٠٢٦

**ليش انعمل:** قبل ما نقدّم `sitemap_index.xml` لجوجل، الـ٤٦ رابطاً كلهم
بينسلّموا للزحف. صفحة عليها `noindex` أو كانونيكال غلط بتضيع شهرين وما
بتنكشف. **فانفحصوا كلهم قبل التسليم لا بعده.**

**كيف:** ٣٨ وكيلاً · سبع مجموعات بتفحص، وكل ملاحظة راحت لوكيل تاني
**مهمّته يكذّبها** لا يأكّدها. اللي تحت **نجا من محاولة التكذيب**.
٥١٩ استدعاء أداة · صفر أخطاء · قراءة فقط بـ`curl` (ولا وكيل لمس المتصفح).

⚠️ **والأسعار الوهمية مستثناة بقصد** · ريّان قرّرها والمخاطرة مقبولة.
اللي تحت **أعطال حقيقية** لا آراء تصميم.

## 🔴 أ · كوبون التجربة `TESTCOD` منشور على كل صفحة

**أخطر وحدة، ولقيتها سبع مجموعات مستقلة.**

الشريط العلوي بيطبع **«خصم 1.00 د.أ · بكود TESTCOD»** وهي **أول كلمات
بالـ`<body>`** · قبل رابط التخطّي حتى. مثبت بايتاً على الرئيسية وعن
والمتجر واليوميات والأسئلة والتواصل والخصوصية والشروط والروتينات
والشركاء وكل صفحة منتج وكل مقالة.

| | |
|---|---|
| مفهرس؟ | ✅ `robots: follow, index` وكانونيكال ذاتي على كلهن |
| مخفي بأي شكل؟ | ❌ `display:flex` وارتفاع 40px |
| بينشال للزاحف؟ | ❌ الإخفاء بـ`localStorage` · والزاحف ما عنده |
| كوبون حقيقي؟ | ✅ **بيقرا سجل كوبون ووكومرس فعلي** |

🔴 **يعني هاد وعد عام بخصم بكود اسمه «تجربة»** · وأي حدا بيقدر يستعمله،
وجوجل بتفهرسه كأول نصّ بالموقع.

**القرار لريّان:** كود وقيمة حقيقيين، أو نطفّي الشريط لحد ما يجهزوا.

`index` ومقدَّمة بخريطة الموقع. يعني نتيجة جوجل للعلامة بتكون **شاشة
دخول**.

**نفس السؤال بينطبق على** `/wishlist/` و`/track/` · أدوات تفاعلية
شخصية، مش صفحات محتوى.

## ✅ واللي طلع سليماً · مهم مثل اللي طلع غلط

- **كل الـ٤٦ بيرجّعوا `200`** · ولا رابط مكسور بالخريطة
- **ولا صفحة عليها `noindex`** غير مقصود
- **كل الكانونيكال ذاتية وصحيحة**
- `robots.txt` سليم وبيدلّ على الخريطة
- `sitemap_index.xml` شغّال · ٤ خرائط فرعية · ٧ مقالات و٢٠ صفحة و١٦ منتجاً و٣ تصنيفات
- ولا قيمة فاضية وصلت الصفحة نصاً (`null` · `undefined` · `NaN` · شورتكود غير مرندر)
