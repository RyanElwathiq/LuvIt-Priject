# نسخ احتياطية من بيانات إلمنتور

كل ملف هون **صورة كاملة** لـ`_elementor_data` تبع صفحة أو قالب، مأخوذة
**قبل** تعديل عليها.

## ليش

🔴 **تعديل بيانات إلمنتور ما بينرجع بـgit**، لأنه بقاعدة بيانات الموقع
مش بملفات الريبو. وصار فعلاً ٢٢ آب: حذفت سكشناً من الرئيسية، وريّان
رجّعني، والنسخة الاحتياطية هي اللي رجّعت كل شي بثانية.

## القاعدة

**خُذ نسخة قبل أي تعديل على إلمنتور · بلا استثناء.**

```js
const p = await G('/wp-json/wp/v2/pages/<id>?context=edit');
await fetch('http://127.0.0.1:4399/<اسم>.json', {method:'POST', body:p.meta._elementor_data});
```
ثم انسخها من الـscratchpad لهون.

## الاسترجاع

```js
const backup = await (await fetch('http://127.0.0.1:4399/<اسم>.json')).text();
await fetch('/wp-json/wp/v2/pages/<id>', {method:'POST', credentials:'include',
  headers:{'Content-Type':'application/json; charset=utf-8','X-WP-Nonce':n},
  body: JSON.stringify({meta:{_elementor_data: backup}})});
```
وبعدها **امسح الكاشين** وإلا بتشوف القديم وبتحكم عليه.
