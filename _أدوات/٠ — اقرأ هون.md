# أدوات المشروع

سكربتات انبنت يوم ٩ آب ٢٠٢٦ وقت بناء الصفحة الرئيسية. كلها **Node عادي بلا أي
تنصيب** · بتستعمل كروم المثبّت على الجهاز.

**شغّلها من مجلد `luvit/`** (مش من هون).

---

## ليش انبنت أصلاً

الوجع القديم: كل تعديل تصميم كان بينتهي بـ«ركّبها وصوّرلي». هاي بتخلي كلود يشوف
بعينه قبل ما يحكم.

**و`chrome --screenshot` ما بتشتغل مع هالصفحة**، جرّبناها وفشلت:
الهيرو canvas بيرسم كل فريم، فالصفحة **ما بتصير idle أبداً**،
و`--virtual-time-budget` بيوقف على شاشة التحميل (علقت على ١٣٪ و٦١٪).
وكمان `--screenshot` ما بيسكرول لأنكور الـURL.

البديل اللي اشتغل: **CDP عبر WebSocket**. Node ٢٤ فيه `WebSocket` عالمي
فما بدها puppeteer ولا playwright.

## الأدوات

### `shoot.mjs` · لقطة لكل سكشن

```
node _أدوات/shoot.mjs <مجلد-الخرج> <الرابط> [العرض] [الارتفاع]
node _أدوات/shoot.mjs ../shots http://localhost:4322/library/home-preview.html 1280 900
```

بيستنى الـloader يوصل ١٠٠٪ فعلياً، وبيسكرول لكل سكشن **بviewport طبيعي**
وبياخد لقطة. وبيكتب `section-map.json` معه.

⚠️ **viewport طبيعي وسكرول حقيقي، مش `captureBeyondViewport` ولا نافذة طويلة.**
الهيرو مثبّت بـScrollTrigger pin، وأي نافذة طويلة بتكسر مواقع كل السكاشن.

### `measure.mjs` · قياس النقاط الحرجة

```
node _أدوات/measure.mjs <الرابط> <العرض> [منفذ]
```

بيرجّع JSON فيه: اتجاه اسم العلامة · تقاطعات الفقاعات · ألوان البادجات ·
هندسة كومة الآراء · الفوتر · أي سكشن ناقصه `data-nav-bg` · الأسعار والنِسَب ·
وهل في سكرول أفقي.

🔴 **وفخ وقعنا فيه:** كان بيحسب بطاقة الآراء **المخفية** (`opacity: 0`) اللي
بيركنها `motion.js` عند `pos > 2`، فبيطلع إزاحة وهمية. **اللقطة بتحسم، مش الرقم.**

### `split-sections.js` · تقطيع الصفحة الرئيسية

بيقص `home-preview.html` لملف لكل سكشن بـ`library/sections/`، وبيحط بأول كل ملف
تعليمات التركيب (`data-nav-bg` · CSS ID · تحذيرات).

🔴 **بيتخطى السكشن ١ والسكشن ٣ عن قصد:**
- **الهيرو** مركّب أصلاً ومصدره `hero-sequence/scroll-sequence.html`
- **الروتينات** ملفها الأصلي فيه **٤ بطاقات** والمعاينة فيها **٣**

⚠️ وبينظّف `</main>` اليتيمة · الصفحة المرجعية بتلفّ السكاشن بـ`<main>`، فقص
السكشن ١٢ كان بياخد معه وسم إغلاق بلا فاتح، ولو انلصق بالإلمنتور بيكسر تخطيط
الصفحة كلها.

### `verify-sections.js` · فحص توازن الوسوم

بيفحص إن كل وسم فاتح إله سكّر بكل ملف سكشن، وإن `data-nav-bg` موجودة بالماركب.

⚠️ **بيفرّغ قيم الـattributes قبل العدّ** · الصور placeholder هي SVG مكتوبة جوّا
`src="data:image/svg+xml,<svg …>"`، وبلا التفريغ بيعد وسوماً جوّا قيمة ويطلع
إنذاراً كاذباً.

## أدوات المزامنة · مش هون

هدول بمجلد `hero-sequence/` لأنهم جزء من دورة الهيرو:

```
node hero-sequence/sync-into-home-preview.js   ← المصدر إلى المعاينة الرئيسية
node hero-sequence/make-local-preview.js       ← المصدر إلى معاينة الهيرو
```

🔴 **الاثنين، بهذا الترتيب، بعد أي تعديل على `scroll-sequence.html`.**
بلاهم بتصير نسخ مختلفة من الهيرو وبتحكم على شي مش موجود على الموقع.

## القاعدة اللي طلعت من كل هذا

**«عدّلت وأعدت التوليد» مش إثبات إن الشي تغيّر.**
بعد أي تعديل: أعد التوليد، والتقط، **وقارن**. وقعنا فيها أكثر من مرة بيوم واحد:
مرة عدّلنا `width` بالـCSS وطلع السكربت بيكتبه inline، ومرة عدّلنا padding وطلع
مدهوساً بترتيب الملف.
